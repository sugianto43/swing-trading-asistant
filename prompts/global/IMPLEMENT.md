# Global Implementation Prompt

Read the master documents and current phase PRD/TDD.

Implement the approved plan for this phase only.

Inspect existing code first. Reuse established patterns where appropriate.
Do not introduce speculative features or future-phase functionality.

After coding:
- format
- lint
- type-check
- run relevant tests
- run regression tests
- fix failures

Report files changed, decisions, tests, failures, limitations, and PRD status.
