# Claude Code Phase Commands

For Phase 3:

/plan-phase 3

After approving the plan:

/implement-phase 3
/test-phase 3
/review-phase 3

After approving review fixes:

/fix-phase 3
/signoff-phase 3

Proceed to Phase 4 only if sign-off returns:
PHASE 3 STATUS: PROCEED

The same workflow applies to phases 1–11.
