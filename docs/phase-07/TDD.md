# Phase 7 — Technical Design Document

## Architecture
Manual execution ledger → position state → P&L/performance → journal.

## Integrity
Execution records append-only/auditable; corrections are explicit adjustments.

## Metrics
P&L, R, win rate, profit factor, expectancy, drawdown, performance by setup/regime.

## Tests
Partial fills, multiple executions, exits, P&L, reconciliation, audit history.
